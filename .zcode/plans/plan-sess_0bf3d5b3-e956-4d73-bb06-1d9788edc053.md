# sebas 全面改名：core / run / router + dispatch

## 目标命名（一次 openspec change：`rename-cli-surface`，落 feat/proc）

```
CLI:    sebas core    ← run       核心长驻服务
        sebas run     ← watchdog  监督守护（隐藏别名 watchdog，兼容已装 systemd unit）
        sebas router  ← gateway   模型路由（隐藏别名 gateway，兼容旧脚本/肌肉记忆）
        sebas webui   （不变）

crate:  sebas-gateway → sebas-router   模型路由本体（用户定名）
        sebas-router  → sebas-dispatch 会话分发（用户定名；RouterHandle→DispatchHandle）

config: [gateway] → [router]（provider_overlay/usage_file）
        [router]  → [dispatch]（state_file）
        env SEBAS_GATEWAY_PROVIDER_OVERLAY → SEBAS_ROUTER_PROVIDER_OVERLAY
        旧键/旧 env 一个发布窗口内「仍生效 + 响亮告警」（config.rs 有 deprecation 先例）
```

**名字映射方向表**（实施与 grep 清零都以此为准）：
- 旧 gateway 族 → 新 router：sebas-gateway、gateway 子命令/GatewayArgs/gateway_cmd.rs/GatewaySpawner/GatewayConfig、`[gateway]`、SEBAS_GATEWAY_*、GatewayAction（commands.rs 里重名残留）→ RouterAction、/api/gateway、GatewayInfo、gateway_listen、gateway-* specs、`--gateway` flag、"gateway started" log、gateway-usage.jsonl（仅文档建议新默认名）
- 旧 router 族 → 新 dispatch：sebas-router、RouterHandle、sebas_router::、`[router]` 节、router-commands spec、src/native_router_bridge.rs→native_dispatch_bridge.rs
- 旧 run 族 → 新 core：run 子命令/RunArgs/CORE_SUBCOMMAND/"run --webui"提法/tests spawn helpers
- 旧 watchdog 族 → 新 run：仅 CLI 子命令面（WatchdogArgs/ExecStart/unit 测试）；watchdog **概念**与 `[watchdog.*]` 配置键不动

**执行顺序关键**：双向互换（gateway→router 且 router→dispatch），必须**先 router→dispatch，再 gateway→router**，最后做 run/watchdog CLI 面，避免中间态撞名。

三义消解（写进 glossary）：CLI `router`=模型路由；`sebas-dispatch`=会话分发；前端 `router.ts`=SPA URL 路由（不动）。
