### A-1 viewer 角色可删除技能仓条目，服务端未拒绝（P1 权限漏洞）
- 复现：viewer 登录 → 设置 → 技能分区 → skill-beta 🗑 可见可点 → 确认 → 删除成功、无错误。

- 附带：其它分区对 viewer 隐藏写控件，技能页没有。

- 实际：空下拉无提示；先建 provider 后流程可走通。

### A-4 设置弹窗失焦时不响应 Esc（P3）
- 焦点在弹窗外 Esc 无效；先点弹窗内再 Esc 正常。

### A-5 usage 折线图最右侧 x 轴标签被截断（P3）
