# 交互蓝图（interaction blueprint）

- 状态：**已于 2026-11-08 获用户批准（1.6）**。用户确认本蓝图、`performance-budget.md` 的硬预算，以及全量替换旧栈、重做核心工作流、一次发布三项方案；后续实现与视觉验收以此为基线。
- 技术前提：React 19.3.1 + AntD 6.7.0，`ConfigProvider` 中文 locale；HTTP/WS、深链、鉴权/RBAC、本地偏好语义不变。
- 可视化预览是**独立静态设计稿，非生产实现**，不安装 React/AntD，不修改生产入口；批准稿随 change 保存为 `react-antd-workbench-blueprint.html`。

## 1. 设计原则

1. **导航轨 + 单工作区 + 会话内待办**：左侧导航承担项目/会话/归档；右侧只有一个工作区；待办不遮罩转录，以工作区顶部内联区呈现。
2. **中性开发工具视觉**：中性色画布、浮岛/分层靠色阶与留缝，单一主强调色（indigo）。禁止营销 hero、装饰性渐变、圆形头像对话、emoji 结构图标。
3. **状态与信号分离**：机器状态（starting/queued/working/waiting/done/failed/dormant）用状态色 + 文字 + 形状；「等你处理」用 signal 色（橙），只用于审批/输入聚焦，不用状态色冒充。
4. **信息密度紧凑但可读**：正文 13px、辅助 12px、标题 20px；行高 1.55；正文最大可读宽度 760px；代码/表格在条目内横滚。
5. **可访问性不是附加项**：普通正文 ≥4.5:1，控件/焦点 ≥3:1；颜色不是唯一状态通道；所有拖拽/排序有非拖拽替代；弹层可 Esc 退出并归还焦点。

## 2. 信息架构

```
应用壳
├─ 导航轨（可收起；窄屏为 Drawer）
│  ├─ 品牌 / 新项目
│  ├─ 用量入口
│  ├─ 项目树（项目 → 会话行；等待组；历史组）
│  └─ 底部：退出/用户、设置
└─ 工作区（唯一主区）
   ├─ 顶栏：项目名 · 执行节点 · 分支 · 聚焦会话 · 连接状态 · 待办计数
   ├─ 会话内待办（审批 / 队列 / 错误，按优先级内联）
   ├─ 转录（未读缝 / 过程折叠 / live tail / 工具配对）
   └─ 输入区（多行输入 · 模式 · 模型芯片 · 发送/停止）
```

设置、用量、登录/首启：设置是**工作区内的工作区**（无独立 URL）；用量保留 `/usage` 深链；登录/首启是全屏门禁。`/sessions` 保留跨项目总览，`/sessions/{key}` 仍聚焦同一工作台，`/settings` 等退休路径仍归一到 `/`。

## 3. 布局规格

| 视口 | 导航轨 | 工作区 | 待办 | 输入区 | 关键约束 |
|---|---|---|---|---|---|
| **1440** | 280px（可调 240–360，可收起） | 剩余宽度；转录 760px 居中，两侧留白 | 顶部内联，最多同时 2 张审批卡 + 1 条队列摘要 | 默认 180px，可拖 120–45% 主区高 | 顶栏 48px；品牌/项目/会话层级清晰 |
| **1024** | 260px；仍常驻 | 转录宽度自适应，最小 560px | 同上，卡片可折行 | 默认 160px | 模型菜单、模式菜单不得溢出主区 |
| **768** | 收起为 56px 图标轨（可见入口，悬停/聚焦展开临时浮层） | 转录占满，左右 16px | 待办默认展开 1 张卡，其余折叠为计数 | 默认 140px | 顶栏压缩：项目名 + 连接 + 待办 |
| **375** | 隐藏，顶部「菜单」按钮打开 Drawer（宽 300px，含 scrim） | 单列，左右 12px | 待办在转录上方，可折叠；审批卡全宽 | 底部输入区，最小 120px | 无横向溢出；触控目标 ≥44px；Drawer Esc/遮罩关闭并归还焦点 |

断点：`>=1200` 桌面三栏比例；`900–1199` 紧凑桌面；`600–899` 图标轨；`<600` Drawer 单列。蓝图预览提供 1440/1024/768/375 四档切换，并在真实视口下用媒体查询验证。

### 尺寸与 token

- 间距：4 / 8 / 12 / 16 / 20 / 24 / 32；圆角：6 / 8 / 12 / 16；阴影仅浮岛/弹层两级。
- 字体：系统 sans / mono，不下载字体；正文 13px，辅助 12px，页标题 20px，rail 行名 13px，代码 12px mono。
- 焦点环：2px 主强调色 + 2px offset，始终可见；不使用 `outline: none` 无替代。
- 主题：`data-theme="dark"` / `"light"`，默认跟随系统；首屏 pre-paint 读取 `sebas:theme`，避免闪烁。

### 对比度（实测值，蓝图色）

| 用途 | 深色 | 浅色 | 要求 |
|---|---|---|---|
| 正文 | `#dde3ee` on `#10141c` = **14.31:1** | `#1b2230` on `#ffffff` = **15.93:1** | ≥4.5 |
| 次要文字 | `#939db1` on `#10141c` = **6.76:1** | `#5b6577` on `#ffffff` = **5.88:1** | ≥4.5 |
| 强调/焦点 | `#8b93ff` = **6.77:1** | `#4f5bd5` = **5.54:1** | ≥3 |
| signal（待你处理） | `#ff9457` = **8.45:1** | `#b45309` = **5.02:1** | ≥4.5 |
| 主按钮白字 | `#ffffff` on `#5b64f2` = **4.62:1** | `#ffffff` on `#4f5bd5` = **5.54:1** | ≥4.5 |

`--sebas-text-faint`（深 3.39:1 / 浅 3.77:1）只用于非必要装饰/禁用态，不承载正文或唯一状态。

## 4. 页面与状态

### 4.1 工作台（`/` 与 `/sessions/{key}`）

- **顶栏**：项目名（粗） + 执行节点 chip（本机/远端状态） + 分支 pill + 聚焦会话友好键 + 连接徽标（ok/warn/error + 文字） + 待办计数。连接徽标常驻但低优先，不与消息争夺。
- **导航轨**：品牌行（可点回 `/`）、用量、项目树、等待组、历史组、底部设置/用户。项目行：名称 + 分支（rail 不显示分支，仅在顶栏/项目头显示）+ 会话数 + `…` 菜单（重命名/移除）+ `+` 新建。会话行：状态点（形状+色+文字）+ 名称 + 预览 + 未读徽标 + `…` 菜单（重命名/归档）。归档行：锁定图标 + 名称 + 归档时刻。
- **待办区**：顺序为「阻塞你的审批 → 运行错误 → 排队提交」。审批卡显示工具名、参数摘要、单次允许/会话级允许/拒绝；并行请求各自独立。队列行显示序号、文本摘要、上移/移除。错误行显示分类与原因，可关闭/重试。待办区不覆盖转录，最多占主区 40%，超出内部滚动。
- **转录**：用户/助手条目左右分区但不使用圆形头像；助手条目显示绑定的 agent 名与状态；thinking/工具过程默认收起为过程折叠（标题 + 计数 + 状态）；工具调用按 `tool_use_id` 配对成一块；未读缝用一条带文字标签的分隔线，不用纯色横线；live tail 为纯文本，结算后转 Markdown；代码/表格在条目内横滚。
- **输入区**：多行 textarea（Enter 发送、Shift+Enter 换行、输入法组合期不拦截）；模式下拉（Ask/Edit/Allow/Auto，单行、allow/auto 等价说明）；模型芯片（诚实显示当前模型；无模型面则不渲染）；发送/停止/排队三态；`/` 命令面板向上弹出；空闲/繁忙/等待审批/starting/failed/断线/只读均有明确文案。
- **状态样本**：未选项目、项目无聚焦会话、加载中、加载失败（重试）、断线（横幅+锁定+输入禁用）、归档只读（恢复按钮）、viewer 只读（可读转录，不能发送）。

### 4.2 项目与会话

- `/sessions`：标题 + 统计 chips（活跃/休眠/启动中/总计）+ 新建表单（项目、agent、任务描述、创建）+ 会话卡片（状态、模型、最近活动、聚焦/关闭）。viewer 隐藏写入口，副标题改为「只读总览」。
- 新建对话框：项目上下文固定；agent 必选且显示不可达原因；模型两级（provider → model）或别名；mode 四选一；上次模型对预选；创建失败就地显示类型化原因，不产生幻影 URL。
- 归档：行内 `…` → 归档确认，明确「终止子进程 + 移入 History + 不可撤销」；有待执行提交时点名丢弃条数；归档视图只读，可恢复；恢复确认说明重建语义。

### 4.3 聚焦对话与审批

- 深链 `/sessions/{key}` 聚焦同一工作台；模型、待办、输入不串会话。
- 审批三语义：单次允许 / 会话级允许（切 auto） / 拒绝；决策后就地反馈并同步转录；迟到/未知请求 404 如实呈现；刷新后按同一 `request_id` 从读模型重建。
- 并行审批：每张卡独立 request_id、独立决策；不允许「一项完成误完成另一项」。
- 停止：运行/泊车态停止控件始终可点，不被输入框遮挡；停止后转录追加中性「回合已停止」条目，控件复位，刷新不复活。

### 4.4 设置工作区（无独立路由）

- 入口：导航轨底部「设置」。打开后工作区切换为设置，地址栏保持原会话 URL；关闭（Esc / 关闭按钮 / 返回）回到原会话与未发送草稿。
- 分区：通用、外观、服务、用户、模型、别名、Agent、技能、环境变量、关于。分区导航固定在设置工作区左侧；内容区独立滚动。
- 角色裁剪：Users 仅 root；Services/Models/别名/Agent 写/Skills 删除与同步仅 root/admin；member/viewer 只见只读列表，写入口不渲染；服务端 403 仍是防线。
- 状态：读取中骨架、读取失败（原因 + 重试）、写入中（按钮 loading + 禁用）、写入失败（就地错误，保留输入）、成功（轻提示，不假装成功）。切换分区保留未提交草稿；删除需确认。
- 外观：系统/浅色/深色、减少动态效果说明；主题即时生效且持久化到 `sebas:theme`。

### 4.5 用量（`/usage`）

- 页头：标题 + 口径说明；控件：来源（全部/router/本地）、粒度（天/小时）、维度（总量/输入/输出/缓存）、刷新。
- 汇总卡：请求数、输入 tokens、输出 tokens、缓存 tokens（窗口合计，与图表同源）。
- 图表：按模型分列的折线，图例可切换；悬停/聚焦显示数值；不依赖外部图表库。
- 状态：加载中、全零空态、router 不可达（原因 + 不画图）、`source=all` 且 router 缺席（局部警示 + 本地数据照常）。

### 4.6 登录 / 首启

- 登录：品牌 + 用户名/密码 + 错误就地显示（不泄露账号是否存在）+ 提交 loading；密码管理器兼容（标准 `autocomplete`/name）；成功后回到深链目标或 `/`。
- 首启：零用户时显示建 root 表单；用户名、密码、确认密码；就地校验（短密码/不一致/弱密码），不提交；409 已存在如实显示；成功后进入工作台。
- 免登录形态：不出现任何门禁；auth 探测期间不闪登录页/工作台（骨架或空白）。

## 5. 键盘与焦点

- 文档顺序：跳过链接 → 品牌 → 用量 → 项目树（项目行 → 会话行）→ 底部设置/退出 → 顶栏状态/待办 → 转录内可交互项 → 输入区（textarea → 模式 → 模型 → 发送/停止）。
- Enter/Space 激活按钮；`Escape` 关闭 Drawer / 弹窗 / 命令面板 / 下拉，并把焦点归还触发元素。
- 深链与聚焦切换后焦点落到工作区标题或转录容器（可读名称），不抢输入框，除非用户从「+ 新建」进入。
- 弹出层（AntD Dropdown/Dialog/Drawer）必须有可访问名称；打开时焦点进入，关闭时归还；不使用焦点陷阱阻断页面其他区域（模态确认除外）。
- 快捷键不新增产品能力：只保留 Enter 发送、Shift+Enter 换行、`/` 命令面板、Esc 关闭、Tab 导航。
- 焦点可见：2px 强调环，深浅主题均 ≥3:1；不以 `outline: none` 移除。

## 6. 减少动态效果

- 遵循 `prefers-reduced-motion: reduce`，并可在设置中显式开启。
- 抑制：抽屉滑入、卡片展开、toast 进入、未读缝动画、流式光标闪烁、图表重绘过渡。
- 保留：状态切换的即时颜色/文字反馈、焦点环、滚动定位（直接跳转而非平滑）。
- 流式输出仍实时追加文本（这是内容而非装饰），但不做逐字动画。

## 7. 状态与视觉信号规范

| 状态 | 颜色 | 额外通道 | 文案 |
|---|---|---|---|
| starting | 蓝 | 旋转/圆点 + `starting` glyph | 启动中 |
| queued | 青 | 队列 glyph | 排队中 |
| working | 琥珀 | 脉冲点（reduced-motion 下静态） | 运行中 |
| waiting | 紫 + signal 边框 | 待办计数 + 文字 | 等待你处理 |
| done | 绿 | 对勾 | 完成 |
| failed | 红 | 感叹号 + 原因 | 失败 |
| dormant | 灰 | 空心点 | 休眠/已归档 |

「等待你处理」同时使用状态紫（机器态）和 signal 橙（人的动作），但不把两者混成一个颜色；颜色始终配文字。

## 8. 蓝图预览的交互与覆盖

- 场景切换：工作台 / 会话总览 / 设置 / 用量 / 登录 / 首启 / 状态样本。

- 主题：跟随系统 / 浅色 / 深色；reduced-motion 开关。
- 可操作演示：选项目/会话、发送消息、流式追加、停止、审批允许/拒绝、队列上移/移除、打开/关闭设置分区、RBAC 角色切换、用量控件、Drawer 开合、断线/恢复、错误重试。

## 9. 1.6 评审需确认的点

1. 三项默认假设：全量替换旧栈、重做核心工作流、一次发布。
2. 导航轨是否保留可拖拽宽度与可收起；`/sessions` 是否继续作为历史总览页。

4. 会话内待办是否只聚合当前会话（非跨会话全局审批）。
5. 未读缝与「跳到最新」的最终形态。
6. 375px 下待办默认展开一张审批卡、其余折叠为计数是否可接受。
7. 性能预算（见 `performance-budget.md`）是否作为硬门槛。
